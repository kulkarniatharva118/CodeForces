# Codeforces Solutions

My solutions to **Codeforces problems and contests**, primarily written in **C++**.

This repository documents my journey in **Competitive Programming**, with a focus on improving problem-solving, algorithmic thinking, data structures, and implementation skills.

## Topics Covered

- Implementation
- Arrays and Strings
- Sorting
- Binary Search
- Prefix Sums
- Two Pointers & Sliding Window
- Hashing
- Greedy Algorithms
- Recursion & Backtracking
- Stacks, Queues & Heaps
- Trees
- Graphs
- Dynamic Programming
- Number Theory
- Bit Manipulation
- Data Structures
- Advanced Algorithms
